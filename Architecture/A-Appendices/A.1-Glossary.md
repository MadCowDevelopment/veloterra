# A.1 Glossary

<details>
<summary>Documentation Hints</summary>

Define domain and technology terms used by this documentation.
</details>

| Term | Definition |
|---|---|
| Base path | URL prefix under which a static deployment is hosted, such as `/veloterra/`. |
| Copper | Base integer unit of VeloTerra currency. |
| Fog | Dark map overlay whose holes represent explored territory. |
| GeoFix | Normalized location observation used by ride processing. |
| H3 | Hierarchical geospatial hexagonal indexing system. |
| Local-first | Architecture in which core behavior and primary runtime persistence do not require cloud availability. |
| Offline region | User-selected geographic bounds and metadata for prefetched map resources. |
| PWA | Progressive Web Application installed and updated from an HTTPS web origin. |
| Reveal | Marking the H3 neighborhood around an accepted fix as explored. |
| RLS | PostgreSQL Row Level Security used to isolate Supabase rows by authenticated user. |
| Service worker | Browser worker that intercepts requests and supplies cached application/map resources. |
| SPA | Single-page application whose routes are resolved in the browser. |
| Wake Lock | Browser API requesting that the screen remain awake while a ride is active. |
