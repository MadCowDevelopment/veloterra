# 10.2 Security Controls

<details>
<summary>Documentation Hints</summary>

Document secure defaults, least privilege, secret handling, privacy, and significant control gaps.
</details>

| Control Area | Implemented Control | Gap / Dependency |
|---|---|---|
| Transport | GitHub Pages, OpenFreeMap, OAuth, and Supabase use HTTPS. | Depends on external providers and browser trust store. |
| Cloud isolation | Private progress remains user-scoped. Shared landmark progress and contributor profiles are readable only by authenticated users. RLS is versioned in repository migrations. | Policies still require deployment verification against the hosted project. |
| Client credentials | Only a publishable Supabase key is shipped. | RLS failure would expose data despite the key being public by design. |
| Production deployment | Main workflow grants read, Pages write, and OIDC token permissions. | Branch protection is an external repository setting. |
| Development deployment | External repository push uses `VELONEXT_DEPLOY_TOKEN`. | Token rotation and exact repository scope are operational responsibilities. |
| Data minimization | Cloud sync is optional; no public/social publication exists. | Ride paths contain sensitive location history when synchronized. |
| Destructive actions | Local reset requires explicit confirmation, stronger for large explored sets. | Cloud data is not deleted by this action. |
| Input filtering | Poor-accuracy fixes and implausible movement steps are ignored for progression. | This is integrity filtering, not anti-cheat security. |
| Restoration spending | Authenticated RPC locks wallet and landmark rows, caps contributions, records an idempotency key, and updates both records in one transaction. | Locally earned coins remain client-asserted until stronger ride attestation exists. |
| Landmark ingestion | Authenticated real rides trigger bounded Edge Function queries with a daily per-user/per-area quota. The function owns catalog writes through a server-only service-role credential; map browsing and simulated fixes cannot populate the catalog. | Public OSM service availability and data quality remain external dependencies. |

## Sensitive Data

- OAuth session tokens in browser-managed storage.
- Downsampled ride paths and timestamps.
- Explored H3 cells, which reveal approximate visited locations.
- Offline-region bounds, which may indicate areas of interest.

No IEC 62443, ISO 27001, or other formal security compliance is claimed.
