# 13.2 Technical Debt

<details>
<summary>Documentation Hints</summary>

Record known shortcuts and missing controls that affect architecture quality.
</details>

| ID | Debt | Consequence | Suggested Resolution |
|---|---|---|---|
| TD-01 | No automated tests. | Regressions depend on manual browser checks and build success. | Add unit tests for economy, fog, tiles, migrations, and sync mapping; add browser smoke tests. |
| TD-02 | `npm run typecheck` is incompatible with the referenced composite configuration. | Documented command fails independently of application errors. | Split app/node checks or remove `--noEmit` from the build-reference invocation. |
| TD-03 | Supabase schema and RLS are not versioned in the repository. | Cloud environments can drift and security controls cannot be reviewed with code. | Add SQL migrations and policy verification. |
| TD-04 | Supabase result errors are not consistently checked. | Some failed sync operations may appear successful. | Centralize checked query results and surface actionable errors. |
| TD-05 | Cell persistence failures are swallowed. | Memory rewards can diverge from durable storage. | Await writes or queue/retry failed mutations. |
| TD-06 | No telemetry or diagnostic logging. | Field failures are difficult to investigate. | Add privacy-conscious local diagnostics and optional error reporting. |
| TD-07 | Wallet is counters rather than an auditable ledger. | Merge uses maxima and cannot explain or reverse rewards. | Introduce immutable reward/spend entries before implementing the game. |
| TD-08 | Simulated progress shares local stores with real preview data. | Development testing can contaminate local counters and later sync. | Use a development database namespace or reversible simulation session. |
| TD-09 | Ride paths grow with every accepted movement step. | Long rides increase local/cloud storage and transfer size. | Define deterministic distance/time-based downsampling. |
| TD-10 | Current UI is metric-only and English-only. | Limits users outside the initial locale. | Add unit and localization abstractions when requirements are prioritized. |
