# 13.1 Risks

<details>
<summary>Documentation Hints</summary>

List architecture risks with impact, probability, mitigation, and ownership where known.
</details>

| ID | Risk | Impact | Probability | Current Mitigation |
|---|---|---|---|---|
| R-01 | Browser suspends foreground tracking or Wake Lock fails. | Incomplete ride and poor user experience. | Medium | Visible foreground-only constraint; Wake Lock requested while active. |
| R-02 | Browser evicts IndexedDB or Cache Storage. | Loss of local progress or offline maps. | Medium | Optional cloud sync for progress; regions can be downloaded again. |
| R-03 | Supabase RLS is missing or incorrect. | Cross-user location/progress disclosure. | Low but severe | Required user-scoped policies; no privileged client key. Policies need repository-managed migrations/tests. |
| R-04 | OpenFreeMap changes availability, style schema, or usage policy. | Online maps and future downloads fail. | Medium | Cached regions continue temporarily; map integration is isolated. |
| R-05 | Fog geometry becomes expensive as explored state grows. | Slow pan/reveal and memory pressure. | Medium | Cells are filtered by viewport before polygon generation. No scale test exists. |
| R-06 | Monotonic sync propagates incorrect progress. | Inflated wallet or explored state cannot be automatically reversed. | Medium | Development ride finish suppresses immediate sync; destructive correction remains manual. |
| R-07 | Development deployment token is compromised or expires. | Dev site tampering or failed deployment. | Low | GitHub secret and repository-scoped permissions; rotation process is undocumented. |
| R-08 | Static GitHub Pages routing/base-path configuration drifts. | Blank application or broken deep links/assets. | Medium | Shared `BASE_URL`, build verification, and generated `404.html`. |
| R-09 | Team migrations or RLS policies are deployed incompletely or out of order. | Team access failure or cross-user location disclosure. | Medium but severe | Ordered repository migrations, explicit function grants, self-only role helpers, and a required hosted authorization test pass. |
| R-10 | A rider loses connectivity or closes the app during live sharing. | A team member sees a position until the short expiry. | Medium | Five-second rate limit, 90-second server expiry, and lifecycle cleanup where the client is able to run. |
