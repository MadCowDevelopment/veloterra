## Purpose

This Software Architecture Document (SAD) describes the implemented VeloTerra system. It supports architecture decisions, development, operation, security review, and future changes.

## Scope

- React progressive web application in this repository.
- Browser storage, offline map caching, and ride tracking.
- Optional Supabase authentication and cloud synchronization.
- GitHub Pages build and deployment environments.
- Current implementation only. Ideas and uncommitted requirements belong in [PLAN.md](../../PLAN.md).

## Audience

- Maintainers and contributors.
- Reviewers assessing architecture, security, or quality.
- Operators maintaining GitHub Pages and Supabase configuration.

## Maintenance

- Update the affected chapter and [version history](../Version-History.md) with material architecture changes.
- Record significant, difficult-to-reverse choices as ADRs.
- Prefer links to code over duplicated implementation details.
