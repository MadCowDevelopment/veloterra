# 2.3 Stakeholders

<details>
<summary>Documentation Hints</summary>

Identify stakeholders and their architecture-related concerns.
</details>

| Stakeholder | Concerns |
|---|---|
| Cyclist | Reliable ride tracking, readable map, offline availability, battery use, privacy, progress durability. |
| Maintainer | Small operational footprint, understandable modules, safe migrations, reproducible deployment. |
| Contributor | Fast local development, testable ride behavior, documented decisions and constraints. |
| GitHub organization owner | Pages availability, least-privilege workflow permissions, deployment token maintenance. |
| Supabase project owner | OAuth configuration, RLS correctness, schema compatibility, free-tier constraints. |
| OpenStreetMap/OpenFreeMap ecosystem | Correct attribution and responsible tile usage. |
