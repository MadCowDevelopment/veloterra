VeloTerra is an installable cycling PWA in which movement reveals a fog-covered map and earns an in-app currency.

## Implemented Capabilities

| ID | Capability |
|---|---|
| FR-01 | Track a foreground ride using browser geolocation. |
| FR-02 | Start, pause, resume, finish, and summarize a ride. |
| FR-03 | Reveal H3 cells around accepted GPS fixes. |
| FR-04 | Award currency for new cells and cooldown-qualified revisits. |
| FR-05 | Persist explored cells, rides, wallet counters, preferences, and offline regions locally. |
| FR-06 | Render live and historical routes on MapLibre maps. |
| FR-07 | Download selected map regions for service-worker-backed offline use. |
| FR-08 | Operate without an account and optionally sign in with Google. |
| FR-09 | Merge local progress with private Supabase data after sign-in. |
| FR-10 | Install and update as a PWA from GitHub Pages. |

## Scope Boundaries

- Tracking is foreground-only.
- Current units are metric.
- There is no public map, leaderboard, social graph, or coin-spending game.
- Offline maps must be downloaded or visited while online before they are needed.
