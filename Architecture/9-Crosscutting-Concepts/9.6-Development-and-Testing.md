# 9.6 Development and Testing

<details>
<summary>Documentation Hints</summary>

Document development-time substitutions, validation, and operational differences between modes.
</details>

| Mode | GPS | Service Worker | Intended Validation |
|---|---|---|---|
| `npm run dev` | Simulated automatically; map clicks emit fixes. | Disabled. | Ride state, movement, map, reveal, rewards, and UI. |
| `npm run build` | Production code path. | Generated. | TypeScript project build and deployable artifact. |
| `npm run preview` | Browser geolocation. | Built artifact behavior. | PWA and offline behavior. |
| GitHub Pages | Browser geolocation. | Enabled. | Device acceptance and production behavior. |

- There is no automated test suite in the repository.
- `npm run build` is the executable CI validation.
- `npm run typecheck` currently conflicts with the referenced composite project when `--noEmit` is applied and is not a reliable validation command.
- MapLibre worker modules are served by Vite middleware in development and copied into the artifact in builds.
