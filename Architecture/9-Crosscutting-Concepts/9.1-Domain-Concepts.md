# 9.1 Domain Concepts

<details>
<summary>Documentation Hints</summary>

Define concepts used across multiple building blocks. Keep terminology aligned with the glossary.
</details>

| Concept | Meaning |
|---|---|
| Ride | A completed tracking session with timestamps, distance, rewards, path, and maximum speed. |
| GeoFix | One browser or simulated position observation with accuracy and optional motion data. |
| Explored cell | An H3 resolution-11 cell revealed by an accepted tracking fix. |
| Reveal neighborhood | Current H3 cell plus one neighboring ring, normally seven cells. |
| New-cell reward | 10 copper for a cell not present in local explored state. |
| Revisit reward | 1 copper after a cell has not been visited for more than six hours. |
| Wallet | Monotonic balance, total-distance, and ride-count counters. |
| Offline region | Bounds and cached URL metadata for a user-selected map area. |
| Map style | One of the configured OpenFreeMap visual styles sharing the same basemap source. |
| Landmark | A named OSM feature normalized into a controlled category, significance tier, fixed restoration cost, and canonical source identity. |
| Restoration | Global progress from zero to a landmark's fixed cost. It is unrestored, under construction, or restored. |
| Contribution | An immutable, attributed debit applied atomically to one restoration by an authenticated user. |

Currency uses copper as its base unit. Display tiers are 100 copper per silver, 100 silver per gold, and 100 gold per diamond.
