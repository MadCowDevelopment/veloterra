# 9.4 Persistence and Migration

<details>
<summary>Documentation Hints</summary>

Describe persistence conventions, schema evolution, consistency, and migration behavior.
</details>

## IndexedDB

- Dexie schema versions are additive: cells in version 1, regions in version 2, rides in version 3.
- Optional ride fields do not require an IndexedDB index migration.
- H3 cells finer than resolution 11 are consolidated into their resolution-11 parents.
- Consolidation retains earliest first visit, latest last visit, and sums visit/reward counters.

## Consistency

- Explored-cell memory state is updated synchronously for immediate rendering and rewards.
- Cell persistence is fire-and-forget; failed `bulkPut` operations are currently suppressed.
- Wallet and preferences use localStorage separately from IndexedDB.
- Ride completion persists the ride before navigation to its summary.
- Offline-region records store all fetched URLs to support reference-counted cache deletion.

## Reset

The Settings danger-zone flow clears explored cells, wallet state, ride history, and offline data through the respective stores/services. Cloud deletion is not part of local reset.
