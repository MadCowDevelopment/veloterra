# 9.2 User Experience

<details>
<summary>Documentation Hints</summary>

Document UX rules that influence multiple screens or components.
</details>

- Mobile-first, full-screen ride map with glanceable HUD controls.
- Large touch targets for start, pause, resume, finish, navigation, and map style.
- Ride controls include an optional heading-up camera mode; turning it off returns north to the top.
- Accepted ride movement is visible as a live teal-to-gold breadcrumb.
- Ride HUD fades during tracking and reappears on pointer interaction.
- The main menu links to a standalone exploration overview. Fog obscures the basemap at every zoom; an explored-area heatmap appears above it at world scale, while neighborhood zoom reveals the basemap only through explored H3 cells. Individual cells expose visit details.
- GPS state and accuracy remain visible in production; development simulation is visibly labeled.
- Currency uses consistent tier colors and shared `CoinAmount` rendering.
- Settings uses an explicit danger zone for destructive local reset.
- Offline selection displays estimated size and live progress before region metadata is saved.
- OpenStreetMap/OpenFreeMap attribution remains visible on maps.
- Current UI is English and metric-only; no internationalization framework is configured.
