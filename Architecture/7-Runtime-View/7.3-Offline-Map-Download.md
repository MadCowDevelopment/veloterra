# 7.3 Offline Map Download

<details>
<summary>Documentation Hints</summary>

Describe the successful and failure paths of offline preparation.
</details>

```mermaid
sequenceDiagram
    participant User
    participant Offline as Offline screen
    participant Downloader as Offline service
    participant OFM as OpenFreeMap
    participant SW as Service worker
    participant Cache as Cache Storage
    participant DB as IndexedDB

    User->>Offline: Select bounds and download
    Offline->>Downloader: downloadArea(bounds)
    Downloader->>OFM: Resolve styles and tile template
    Downloader->>Downloader: Enumerate assets through zoom 14
    loop Pool of 8 requests
        Downloader->>OFM: Fetch asset
        OFM-->>SW: HTTPS response
        SW->>Cache: CacheFirst entry
    end
    Downloader-->>Offline: URLs, bytes, progress
    Offline->>DB: Save region metadata
```

- The estimated download is rejected above 100 MB.
- All configured styles, relevant glyph ranges, sprites, low-zoom raster, and vector tiles are prefetched.
- Missing nonessential tiles are skipped; cancellation propagates through `AbortSignal`.
- The flow requires an active service worker and therefore cannot complete under `npm run dev`.
- Region deletion uses stored URL references so assets shared with another region remain cached.
