# 7.4 Cloud Synchronization

<details>
<summary>Documentation Hints</summary>

Describe synchronization triggers, ordering, merge semantics, and error handling.
</details>

```mermaid
sequenceDiagram
    participant App
    participant Sync
    participant Local as Local stores and IndexedDB
    participant Cloud as Supabase

    App->>Sync: Login, visible tab, manual request, or ride finish
    Sync->>Sync: Skip if signed out or already running
    Sync->>Local: Normalize legacy H3 cells
    Sync->>Cloud: Read explored snapshot
    Sync->>Local: Insert cloud-only cells
    Sync->>Cloud: Upsert union of cells
    Sync->>Cloud: RPC sync lifetime earnings and counters
    Cloud->>Cloud: Preserve authoritative spent amount
    Cloud-->>Sync: Return earned, spent, and derived balance
    Sync->>Local: Apply cloud wallet result
    Sync->>Cloud: Read rides
    Sync->>Cloud: Upsert local-only rides
    Sync->>Local: Upsert cloud-only rides
    Sync-->>App: Synced timestamp or error status
```

Exploration and ride merging remain monotonic. Wallet earnings merge monotonically, while spending is recorded only by server-side transactions and is therefore not overwritten by an offline device.

## Landmark Restoration

```mermaid
sequenceDiagram
    participant Rider
    participant App
    participant Discovery as Edge Function
    participant OSM as Overpass
    participant Cloud as Supabase

    Rider->>App: Reveal new cells during a real ride
    App->>Discovery: Discover bounded area around accepted fix
    Discovery->>Discovery: Verify authenticated user and bounds
    Discovery->>OSM: Query named landmark candidates
    Discovery->>Cloud: Classify, price, and insert new landmarks
    Rider->>App: Open exploration view
    App->>Cloud: Read landmarks in viewport
    App->>App: Keep landmarks in locally explored H3 cells
    App->>Cloud: Read visible global progress
    Rider->>App: Choose contribution amount
    App->>Cloud: Atomic contribution RPC
    Cloud->>Cloud: Lock wallet and landmark, debit, append ledger
    Cloud-->>App: Updated balance and progress
    Cloud-->>App: Realtime landmark update
```
